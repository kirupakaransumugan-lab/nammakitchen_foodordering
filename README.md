# Namma Kitchen — Food Ordering System

Single-restaurant online food ordering platform (Admin, Restaurant Owner, Customer).

- **Frontend:** React + Vite + Fetch API (`frontend/`)
- **Backend:** FastAPI + Uvicorn + Pydantic + SQLAlchemy (`Backend/`)
- **Database:** MySQL `food_ordering_db`
- **Security:** JWT + Argon2 + CORS + role-based authorization
